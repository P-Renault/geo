GEOTRACIA — RESTAURACIÓN DE INFORMES Y EXPORTACIONES
Paquete diferencial: solo archivos de integración.

Archivos:
- index.html: conserva las referencias a scripts y módulos existentes; actualiza la versión del CSS para invalidar caché.
- app.js: conserva el enrutamiento del módulo "informes", la función reports() y sus acciones existentes.
- styles.css: mantiene los estilos actuales y el ajuste de alineación.

Integración:
1. Haz una copia de seguridad de los tres archivos actuales.
2. Reemplaza los tres archivos en la raíz del repositorio por los de este paquete.
3. Verifica que no se haya omitido ningún archivo CSS/JS externo ya referenciado en index.html.
4. Publica en GitHub Pages y realiza una recarga forzada.

Nota: este paquete restaura el código del módulo de Informes y exportaciones que existe en la versión fuente geo-Desarrollo-1.0. No modifica Supabase.
La interfaz actual contiene acciones de demostración para generar informes y algunos formatos aparecen marcados como pendientes; no se debe interpretar eso como exportación PDF/KML productiva.
