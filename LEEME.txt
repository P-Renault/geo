GEOTRACIA — Ajuste CSS de tarjetas de suscripción

Archivo incluido: styles.css

Integración:
1. Reemplazar el archivo styles.css existente por este archivo completo.
2. Publicar el cambio en GitHub Pages.
3. En móvil, recargar la página forzando actualización de caché.

Este paquete solo modifica estilos. No cambia app.js, Supabase, tablas ni políticas RLS.
